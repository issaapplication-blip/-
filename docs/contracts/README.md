# RAFIQ — حزمة العقود الأولية للمراجعة

> هذه الملفات **مسودات تشغيلية للمراجعة** وليست عقودًا قانونية نهائية ولا بديلاً عن مراجعة محامٍ مرخّص في لبنان قبل التوقيع أو الاعتماد الإنتاجي.

## نطاق الحزمة
1. عقد المنصة مع العائلة/طالب الخدمة.
2. عقد مقدم الرعاية.
3. عقد الممرض/الممرضة.
4. اتفاقية شريك مختبر.
5. اتفاقية شريك مركز أشعة/CT.
6. اتفاقية بيع/تأجير المعدات الطبية.

## قواعد مشتركة
- القرار النهائي في العقود، القبول، التوظيف، المطابقة، الأموال، الرواتب، العمولات، الشركاء والاستثناءات يعود إلى الإدارة، وليس إلى الوكيل الذكي.
- العمولة التشغيلية الافتراضية للمنصة: **20%** من قيمة الخدمة/المعاملة وفق أساس الاحتساب الذي يقرره العقد النهائي.
- التسوية المالية: عبر **Whish Money** أو وسيلة دفع تعتمدها الإدارة خطيًا.
- لا يجوز لأي طرف تجاوز المنصة أو ترتيب تعامل خارجها مع طرف تم التعارف إليه عبر المنصة خلال فترة الحماية التعاقدية، إلا بإذن كتابي من الإدارة أو وفق الاستثناءات التي يحددها العقد النهائي.
- البيانات الصحية والشخصية لا تستخدم إلا للغرض المحدد، وبقدر الحاجة، مع تقييد الوصول والتخزين الآمن ومدة احتفاظ تحدد بعد المراجعة القانونية.
- أي معالجة أو إفصاح لجهة ثالثة يجب أن يكون له أساس مشروع ومعلن، وبالقدر اللازم لتنفيذ الخدمة أو المتطلبات القانونية.
- العقود لا تمنح المنصة سلطة تشخيص أو وصف علاج أو تعديل وصفة طبية.
- الإلغاء، الشكاوى، الحوادث، المسؤولية، القوة القاهرة، والاختصاص القضائي تبقى بنودًا قابلة للمراجعة القانونية.
- التقييم الأسبوعي إداري/تشغيلي، ولا يحول دون حق الطرف المتضرر في تقديم شكوى أو طلب مراجعة.

## حقول يجب تعبئتها قبل الاعتماد
- اسم الطرف/الشركة القانوني.
- رقم الهوية/السجل عند الحاجة وبعد تحديد المتطلبات القانونية.
- العنوان ووسيلة الاتصال.
- نطاق الخدمة ومكانها.
- السعر والعملة وأساس العمولة.
- تاريخ البدء والانتهاء.
- سياسة الإلغاء والاسترداد.
- مدة منع التجاوز.
- مدة الاحتفاظ بالبيانات.
- جهة الاختصاص وآلية فض النزاع.
- اسم وتوقيع المفوض عن كل طرف.
