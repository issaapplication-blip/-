# RAFIQ | دليل المستشفيات — نطاق ومصدر البيانات

آخر تحديث: 2026-11-28

## النطاق
هذه الدفعة تخص المستشفيات فقط. لا تتضمن المختبرات أو مراكز الأشعة أو العلاج الفيزيائي أو موردي/مؤجري المعدات الطبية. لا تعني إضافة المستشفى وجود شراكة أو موافقة إعلان.

## مصدر الدفعة الأولى
دليل المنشآت الصحية التابع لوزارة الصحة العامة اللبنانية:
- https://staging.moph.menaws.com/en/Pages/3/20129/توزّع-المنشآت-الصحيّة-20000?page=80
- https://staging.moph.menaws.com/en/Pages/3/20129/توزّع-المنشآت-الصحيّة-20000?page=82

تم نقل الاسم ورقم الهاتف والمنطقة كما ظهرت في سجل الوزارة. في عدة سجلات، لا يقدم المصدر شارعاً ورقم مبنى؛ لذلك يعرض RAFIQ القضاء/المنطقة كمستوى العنوان المتاح، ولا ينشئ عنواناً تفصيلياً من التخمين.

## الإحداثيات
حقلا latitude وlongitude يبقيان NULL حتى التحقق من موقع المستشفى بدقة. لا تُرسم علامات خريطة اعتماداً على اسم البلدة فقط.

## النشر والخصوصية
- تعرض الواجهة العامة الصفوف التي is_published=true فقط.
- يسمح RLS بالقراءة العامة لهذه الصفوف فقط.
- تتطلب عمليات الإدارة حساباً مخولاً عبر public.is_admin().
- is_published تعني ظهور سجل دليل عام فقط، ولا تعني شراكة تجارية أو اعتماد عرض أو خصم.
- لا تخزن هذه الدفعة أرقاماً شخصية؛ الأرقام من دليل المنشآت.
