## قواعد التسجيل والتحديث

- عند إضافة جهة جديدة: الاسم + رقم الهاتف بصيغة E.164 + الاختصاص + المنطقة إن وجدت + البريد إن وجد.
- إذا كانت الجهة تعمل في أكثر من اختصاص، تسجل في كل قائمة مناسبة مع الحفاظ على نفس رقم الهاتف والاسم.
- لا يوصف الشخص بأنه «مجاز» أو «مرخص» إلا إذا كانت المعلومة مؤكدة.
- حالة كل جهة يجب أن تتبع: `مسجل → رسالة أولى → رد → مسؤول/بريد رسمي → عرض شراكة → موافقة خطية → اتفاق → شريك معتمد`.
- لا يتم إرسال الرسالة الثانية تلقائيًا؛ يتم اختيارها بناءً على الرد الفعلي للجهة.
