## قواعد التسجيل والتحديث

- عند إضافة جهة: الاسم القانوني أو التجاري، الهاتف بصيغة E.164، البريد، العنوان والمنطقة، فئة الخدمة، رابط المصدر، وتاريخ التحقق.
- إذا عملت الجهة في أكثر من اختصاص، تسجل في كل فئة مع الحفاظ على هوية موحدة لتجنب التكرار.
- لا يوصف أي مركز أو مهني بأنه مرخص أو معتمد إلا بعد التحقق من مصدر رسمي مناسب.
- لا تُخمن بيانات الاتصال الناقصة؛ اكتب «غير متاح» أو «بحاجة إلى تأكيد».
- حالات المتابعة: مرشح، بيانات قيد التحقق، رسالة معدّة، أُرسلت بموافقة الإدارة، رد وارد، عرض مستلم، قيد المراجعة، يحتاج إلى استكمال، مقبول، مرفوض، اتفاق مكتوب، إعلان منشور، متوقف.
- لا يتحول أي مرشح إلى شريك معتمد لمجرد إدراجه أو إرسال رسالة إليه.
- لا يُنشر اسم أو شعار أو عنوان أو رقم أو سعر أو عرض لأي جهة قبل موافقة الإدارة الخطية وتأكيد الجهة لصحة البيانات.
- لا ترسل رسائل أو تنفذ اتصالات آلية.
