# RAFIQ — Discount Approval Policy

Last reviewed: 2026-11-23

## No fixed discount schedule

RAFIQ does not publish a universal discount percentage, fixed amount, or calculation formula. The value depends on the exact service and the current price agreed with the approved provider.

Examples include:
- Laboratory: routine panels, hormone tests, vitamins, oncology-related tests, and individual tests.
- Imaging: X-ray, ultrasound/echo, MRI, CT/scanner, ECG, EEG, and other modalities.

## Approval sequence

1. Record the exact requested service and, when known, the provider and area.
2. Management confirms the provider's current price and whether the provider has approved a discount.
3. Management records the discount basis (percentage or fixed amount), value, currency, eligibility, validity, and terms.
4. Generate a unique code only after approval. Each code is limited to one use.
5. Share the code only through an official RAFIQ channel.
6. Mark the code as used only after the provider confirms redemption. Preserve a private audit record.

## Prohibited behavior

- Do not invent or estimate a provider price, discount, code, expiry, or availability.
- Do not promise a discount before management approval.
- Do not commit live codes, customer identifiers, contact details, quotations, or redemption records to this repository.
- Do not treat a message sent by the customer as proof that the provider redeemed the code.

## Operational storage

Use only an approved private, access-controlled register for live codes and redemption details. This document defines policy; it is not a live discount ledger.
