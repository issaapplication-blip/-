# RAFIQ discount-code register

This directory is a template and procedure only. The GitHub repository is public: never add live codes, customer names, phone numbers, recipient identifiers, or redemption records here.

## Approval and one-time issue
1. Management chooses the service category.
2. Management approves the exact discount percentage, eligibility, validity dates, and terms.
3. Only after approval, create a unique unpredictable code in a private, access-controlled register. Never store live codes in this public repository.
4. Set max_uses=1. Mark the code issued only when sent through an official RAFIQ WhatsApp or Telegram account.
5. After redemption is confirmed, mark it used with a timestamp. A used code is permanently closed and cannot be reused.
6. Mark unused withdrawn codes cancelled or expired as applicable.
7. The assistant must never invent a discount percentage or code.

## Status values
- pending_approval
- approved
- issued
- used
- cancelled
- expired

The adjacent CSV is an empty schema template, not a live register. Keep actual codes in private admin-controlled storage.
